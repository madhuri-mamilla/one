# Thali

An Indian-home-kitchen recipe app for people who have no time or energy left to decide what to cook.

**Tech stack:** React + TypeScript + Vite, React Router, localStorage-backed placeholder auth and favorites.

**Status:** work in progress — V1 (login placeholder, recipe feed with filters, recipe detail, favorites) is built. More to come.

## Development

```
npm install
npm run dev
```

## Deployment

Pushes to `main` build and deploy the app to GitHub Pages via `.github/workflows/deploy.yml`, served at `https://<owner>.github.io/one/`.
